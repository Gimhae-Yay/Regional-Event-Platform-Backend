| 소유 범위 | 운영 통계 대시보드, 콘텐츠별·회차별 예약 및 방문 지표 |

> 이 문서는 P2 운영 통계의 기능 계약을 정의한다. 지표 산식과 갱신 방식은 구현 전에 지표 사전으로 확정한다.

## 1. 범위

### P2-FR-01. 운영 통계 대시보드

- 역할별 권한과 지역 범위 안에서 운영 지표를 조회한다.
- 지표마다 기간, 시간대, 기준 시각과 정의 버전을 표시한다.
- 대시보드는 집계 결과를 제공하며 원본 예약·방문·결제·혜택 상태를 변경하지 않는다.

### P2-FR-02. 콘텐츠·회차별 예약 및 방문 지표

- 콘텐츠 단위 또는 회차 단위로 예약과 방문 지표를 조회한다.
- 필터·정렬·비교에 사용하는 기간과 지역 범위를 지표 결과와 함께 명시한다.
- 원본 데이터 변경 또는 집계 재처리로 수치가 달라지면 기준 시각과 지표 버전으로 재현할 수 있어야 한다.

## 2. 유저 시나리오

### US-P2-01. 운영 주체가 담당 범위의 운영 성과를 확인한다

- **주체:** 콘텐츠 운영자, 지역 관리자 또는 전체관리자
- **목표:** 담당 지역·콘텐츠·회차의 예약과 실제 방문 흐름을 같은 기준으로 확인한다.
- **선행 조건:** 지표 사전, 사용자 권한과 집계 대상 원본 데이터가 확정돼 있다.

#### 기본 흐름

1. 사용자가 대시보드에서 기간, 지역과 콘텐츠 또는 회차 범위를 선택한다.
2. 시스템은 역할·`region_id`·콘텐츠 소유 관계에 따라 허용된 조회 범위를 계산한다.
3. 시스템은 지표 정의 버전과 기준 시각에 맞는 집계 결과를 조회한다.
4. 시스템은 예약·방문 지표와 필터, 시간대, 기준 시각을 함께 표시한다.
5. 사용자는 필요한 경우 콘텐츠와 회차 단위로 결과를 전환해 비교한다.

#### 예외 흐름

- 권한 없는 지역·콘텐츠·회차를 직접 식별자로 요청해도 결과를 제공하지 않는다.
- 기간·시간대·포함 상태가 정의되지 않은 지표는 정식 대시보드에 노출하지 않는다.
- 집계가 지연됐거나 재계산 중이면 최종성 여부와 기준 시각을 숨기지 않는다.

**적용 정책:** `DST-01`~`DST-04`

## 3. 운영 통계 정책

- `DST-01`:
  모든 지표는 지표명, 목적, 분자·분모, 단위, 기간, 시간대, 필터, 포함·제외 상태와 정의 버전을 가진다.
  예약 건수·예약자 수·방문 건수·방문자 수처럼 혼동 가능한 수치는 별도 지표로 정의한다.
- `DST-02`:
  콘텐츠 운영자는 자신의 콘텐츠, 지역 관리자는 담당 지역, 전체관리자는 확정된 전역 범위만 조회한다.
  집계 쿼리·캐시·내보내기 경로 모두에 같은 권한 범위를 적용한다.
- `DST-03`:
  집계 결과는 원본 데이터의 기준 시각과 지표 정의 버전을 보존한다.
  원본 보정, 재집계 또는 정의 변경이 있으면 이전 결과를 임의로 같은 의미의 수치로 표시하지 않는다.
- `DST-04`:
  대시보드에는 목적에 필요한 비식별 집계만 제공한다.
  소수 집계의 노출 제한, 드릴다운 허용 범위, 원시 데이터 접근과 외부 내보내기 기준은 구현 전에 확정한다.

## 4. 구현 전 확정 항목

| 항목 | 확정할 내용 |
| --- | --- |
| 지표 목록 | 운영 대시보드의 필수 지표와 콘텐츠·회차별 필수 비교 항목 |
| 산식·상태 | 예약·방문·취소·노쇼·환불 등 어떤 상태를 분자·분모에 포함할지 |
| 집계 기준 | 서비스 시간대, 일·주·월 경계, 갱신 주기, 지연 허용 범위와 재집계 절차 |
| 권한·비식별화 | 역할별 드릴다운·내보내기 범위와 소수 집계 보호 방식 |
| 저장 전략 | 실시간 계산·사전 집계·캐시의 선택, 지표 버전·재처리 보관 방식 |

## 5. 데이터 요구사항

| 데이터 | 핵심 식별·연결 정보 | 용도 |
| --- | --- | --- |
| 지표 정의 | 지표명, 버전, 산식, 기간·시간대, 포함 상태 | 결과 해석과 변경 관리 |
| 집계 결과 | 지표, `region_id`, 콘텐츠·회차 식별자, 기간, 기준 시각, 값 | 대시보드 조회 |
| 집계 실행 이력 | 실행 식별자, 원본 기준 시각, 지표 버전, 성공·실패 정보 | 지연·재집계 추적 |
| 원본 운영 데이터 | 예약, 방문, 콘텐츠·회차, 혜택·거래의 상태 이력 | 집계 근거 |

상세 엔티티, 컬럼, 관계, 인덱스와 보관 정책은 [ERD](../erd.md)에 확정한다.
