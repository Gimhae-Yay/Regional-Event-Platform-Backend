# API 공통 규칙

## Base URL

```text
/api/v1
```

## 요청과 응답 형식

| 항목           | 규칙                                |
|--------------|-----------------------------------|
| 요청·응답 미디어 타입 | `application/json; charset=UTF-8` |
| 문자 인코딩       | UTF-8                             |
| 시각           | 콘텐츠의 생성·수정·심사·처리 이벤트 시각은 ISO 8601 UTC `Z` 문자열로 표현한다. 콘텐츠 일정값만 ISO 8601 `+09:00` 오프셋 문자열로 표현한다. |
| 식별자          | 경로·요청·응답의 리소스 식별자는 `String` 양의 10진 문자열로 표현한다. |
| `null`       | `ApiResponse.data`는 항상 포함하며 데이터 없는 성공·실패에는 `null`을 사용한다. API별 응답 DTO의 nullable 필드는 해당 API 명세에 정의한다. |
| 컬렉션          | 빈 결과를 빈 배열로 반환한다.                    |

## 공통 입력 원칙

- 요청 JSON 문법, 필수값, 타입 또는 범위 위반의 오류 코드와 HTTP 상태는 [응답·오류](response-and-error.md)를 따른다.
- API별 입력 필드의 형식, 범위와 `null` 허용 여부는 해당 도메인 명세의 `Request Field`에 명시한다.
- 공통으로 쓰는 식별자나 기간 입력 규칙이 확정되면 아래 표에 한 번만 추가한다.

| Name         | Type     | Required | Description |
|--------------|----------|----------|-------------|
| 리소스 식별자 | String | API별 | 경로·요청에서 양의 10진 문자열로 전달하며 응답에서도 같은 문자열 표현을 사용한다. |
