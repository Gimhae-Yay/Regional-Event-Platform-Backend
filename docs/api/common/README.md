# API 공통 계약

이 디렉터리는 여러 도메인 API가 공유하는 HTTP 계약의 단일 출처다. 개별 도메인 명세는 공통 규칙을 복사하지 않고
아래 문서를 링크한다. API별 권한, 상태 전이, 요청·응답 필드와 오류 코드는 각 도메인 명세가 소유한다.

| 문서                              | 소유 범위                                 |
|---------------------------------|---------------------------------------|
| [API 공통 규칙](api-conventions.md) | Base URL, 미디어 타입, 시간·식별자 표기와 공통 입력 원칙 |
| [인증·인가](authentication.md)      | 인증 전달 방식과 역할·지역·소유권 표기 규칙             |
| [응답·오류](response-and-error.md)  | 공통 성공·오류 응답 구조, HTTP 상태와 오류 코드 작성 규칙  |
| [페이지네이션](pagination.md)         | 목록 API의 페이지·정렬·필터 계약                  |

공통 계약의 값이 아직 확정되지 않은 항목은 `{중괄호}` 자리표시자로 남긴다. 정책이나 채택 ADR이 값을 확정하면
관련 공통 문서와 해당 도메인 API를 같은 변경에서 갱신한다.
