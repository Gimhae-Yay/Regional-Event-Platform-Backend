# 미션 자동 공개 제외 정책

## 1. 개요

미션 공개는 지역 관리자 승인 API에서 즉시 `PUBLISHED`로 전이한다. 별도 예약 공개 시각과 자동 공개 후보 상태를
두지 않으므로 자동 공개 Scheduler는 구현 대상에서 제외한다.

### 실행 계약

| 항목 | 내용 |
| --- | --- |
| 실행 방식 | 지역 관리자 승인 HTTP API |
| 자동 공개 Scheduler | 구현하지 않음 |
| 공개 Endpoint | `POST /api/v1/region-admin/missions/{missionId}/approve` |
| 관련 요구사항 | `P1-FR-03`, `MSN-01` |
| 기준 정책 | 미션은 지역 관리자 승인 즉시 공개된다. 확인되지 않은 예약 공개 시각 조건은 추가하지 않는다. |
| 구현 판정 | 채택 ADR 기준으로 별도 자동 공개 Scheduler를 구현하지 않는다. |
| 실행 결과 | Scheduler 실행, 상태 전이, 감사 이벤트 모두 없음 |

### 처리 규칙

1. ADR-0066은 미션을 지역 관리자 승인 성공 시 즉시 공개하며 별도 예약 공개 시각을 두지 않는다.
2. 자동 공개를 새로 요구하려면 PRD와 후속 ADR로 공개 후보 조건을 먼저 확정해야 한다.
3. 시간 경과만으로 `DRAFT` 또는 `PENDING_REVIEW` 미션을 공개하지 않는다.
4. Scheduler 컴포넌트, 후보 조회와 자동 공개 상태 전이 코드를 만들지 않는다.

### 비실행 검증

1. `PENDING_REVIEW` 미션은 시간이 지나도 자동으로 `PUBLISHED`가 되지 않는다.
2. 공개는 지역 관리자 승인 API의 `PENDING_REVIEW → PUBLISHED` 전이로만 발생한다.
3. 승인 처리 실패 시 미션은 `PENDING_REVIEW`를 유지하고 자동 공개 작업이나 보상 작업으로 우회하지 않는다.
