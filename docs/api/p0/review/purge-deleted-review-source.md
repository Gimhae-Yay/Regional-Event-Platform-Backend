## 7. 후기 삭제 30일 뒤 원문 영구 파기

이 기능은 외부 클라이언트가 호출하는 HTTP API가 아닌 내부 스케줄러 작업이다.
삭제 후 30일이 지난 후기의 별점과 텍스트 원문을 영구 파기하되 후기 행과 방문당 후기 유일 연결은 보존한다.

### 실행 계약

| 항목 | 계약 |
| --- | --- |
| 실행 경로 | `scheduler` |
| 실행 주체 | 애플리케이션 내부 스케줄러 |
| 외부 HTTP 경로 | 없음 |
| 인증·인가 | 없음. 외부 요청을 받지 않는다. |
| 요청 본문·응답 본문 | 없음 |
| 시간 기준 | 애플리케이션 서버 시계가 아닌 MySQL 현재 시각 |
| 실행 주기 | 1시간마다 실행한다. `deleted_at + 30일`이 지난 후 최초 실행에서 파기하며 정상 운영 기준 최대 지연은 1시간이다. |

### 처리 대상과 변경

| 대상 조건 | 변경 | 유지 |
| --- | --- | --- |
| `status = DELETED`, `deleted_at + 30일 <= MySQL 현재 시각`, `rating IS NOT NULL` 또는 `review_text IS NOT NULL` | `rating = NULL`, `review_text = NULL`, `updated_at = MySQL 현재 시각` | 후기 행, `DELETED` 상태, `deleted_at`, `visit_id`, `content_id`, `region_id`, 작성자 연결의 현재 상태, `created_at` |

### 처리 규칙

1. 파기 대상은 `status = DELETED`이고 `deleted_at + 30일 <= MySQL 현재 시각`인 후기다.
2. `rating`과 `review_text` 중 하나라도 남아 있는 행만 파기 갱신 대상으로 선택한다.
3. 조건부 갱신으로 `rating`과 `review_text`를 함께 `NULL`로 변경하고 `updated_at`을 같은 MySQL 현재 시각으로 갱신한다.
4. 후기 행을 물리 삭제하지 않고 `visit_id` 유일 연결을 영구 보존해 같은 방문의 후기 재작성을 차단한다.
5. `status`, `deleted_at`과 관계 필드는 변경하지 않으며 파기 시계를 다시 시작하지 않는다.
6. `PUBLISHED` 후기와 삭제 후 30일이 지나지 않은 후기는 변경하지 않는다.
7. 회원 탈퇴 여부는 기존 삭제 후기의 파기 기준과 시각에 영향을 주지 않는다. 파기 작업은 `user_id`와 `author_unlinked_at`을 변경하지 않으며 별도 탈퇴 흐름의 작성자 연결 제거를 막지 않는다.
8. 이미 별점과 원문이 모두 `NULL`인 후기는 성공 처리와 감사 이벤트를 중복 생성하지 않는다.
9. 다중 인스턴스나 중복 실행에서도 대상 조건을 포함한 조건부 갱신에 성공한 처리만 원문 파기 감사 이벤트를 생성한다.
10. 후기 한 건의 원문 파기와 성공 감사 이벤트는 하나의 트랜잭션에서 함께 커밋한다.
11. 한 후기의 처리에 실패하면 해당 트랜잭션을 롤백하고 다음 실행에서 재시도할 수 있게 한다. 다른 후기의 처리 여부는 운영 배치 경계에서 격리한다.
12. 정상 운영에서 파기 예정 시각을 1시간 넘긴 미파기 대상은 운영 경고로 기록하고 다음 실행에서 우선 재시도한다.
13. 스케줄러는 외부 API 응답을 만들지 않으며 대상·성공·실패 건수와 실패 사유는 원문 없이 구조화 로그와 감사 기록으로 관찰한다.

### 감사 및 정합성

- 성공 감사 이벤트는 대상 유형 `REVIEW`, `review_id`, 시스템 처리 시각과 원문 파기 성공을 재현할 수 있어야 한다.
- 시스템 작업이므로 감사 이벤트에 사용자 처리자 연결을 만들지 않는다.
- 감사 이벤트, 애플리케이션 로그와 오류 로그에 별점 또는 후기 원문을 복사하지 않는다.
- 파기 후 `review.status = DELETED`, `deleted_at IS NOT NULL`, `rating IS NULL`, `review_text IS NULL` 불변 조건을 만족해야 한다.
- 실패한 후기는 별점과 원문이 모두 파기되거나 모두 유지되도록 한 트랜잭션에서 처리한다.
