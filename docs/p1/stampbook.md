# 스탬프북

| 항목 | 내용 |
| --- | --- |
| 상위 명세 | [로컬스탬프 P1 명세](../p1-spec.md) |
| 소유 범위 | 스탬프북 생성·수정·공개·종료, 방문 완료 기반 적립, 내 목록·상세·적립 이력과 완료 보상 발급 정보 조회 |
| API 명세 | [API 명세서](../api/api-specification.md) |

> 이 문서는 P1 스탬프북 정책의 단일 기준이다. 상태 전이, 대상 콘텐츠별 적립과 쿠폰 완료 보상은
> ADR-0066·ADR-0067 및 P1 ERD를 따른다.

## 1. 범위

### P1-FR-01. 스탬프북 운영

- 콘텐츠 운영자는 담당 지역·콘텐츠 범위에서 `DRAFT` 스탬프북을 생성·수정하고 검토를 요청한다.
- 담당 지역 관리자가 승인한 `PUBLISHED` 스탬프북만 방문자에게 공개한다.
- 공개된 스탬프북은 종료할 수 있으며 종료 시점과 처리 사유를 기록한다.
- `PUBLISHED` 뒤에는 핵심 값 수정 없이 종료만 허용하며, 생성·수정·검토 요청·승인·반려·종료는 다른 지역 또는 소유 범위 밖에서 수행할 수 없다.

### P1-FR-02. 방문 기반 스탬프 적립과 조회

- P0에서 생성된 유효 방문 기록을 근거로 스탬프 적립을 반영한다.
- 방문자는 본인에게 공개된 스탬프북 목록, 스탬프북 상세와 적립 이력을 조회할 수 있다.
- 적립 처리의 재시도 또는 같은 방문 이벤트의 중복 전달은 새 적립을 만들지 않는다.

## 2. 유저 시나리오

### US-P1-01. 운영 주체가 스탬프북을 공개하고 종료한다

- **주체:** 권한 있는 콘텐츠 운영 주체
- **목표:** 담당 지역의 반복 방문 활동을 하나의 스탬프북으로 안내한다.
- **선행 조건:** 주체에게 담당 `region_id`와 필요한 콘텐츠 소유 권한이 있다.

#### 기본 흐름

1. 콘텐츠 운영자가 같은 지역의 하나 이상 대상 콘텐츠와 완료 보상을 입력해 `DRAFT` 스탬프북을 만든다. 완료 보상은 같은 지역의 `STAMPBOOK_COMPLETION` 쿠폰 정책만 선택할 수 있다.
2. 시스템은 소유 관계와 필수 정책 정보를 검증한 뒤 `PENDING_REVIEW` 검토 요청을 저장한다.
3. 담당 지역 관리자가 검토를 승인하면, 잠근 완료 보상 정책이 `PUBLISHED`인지 확인한 뒤 스탬프북을 `PUBLISHED`로 전이해 방문자에게 노출한다. 반려하면 `DRAFT`로 돌려 수정 후 재요청하게 한다.
4. 운영 주체가 운영을 마치면 종료 요청과 사유를 남긴다. 공개 뒤에는 종료만 할 수 있다.
5. 시스템은 종료 후 신규 적립 대상에서 제외하고 기존 이력은 보존한다.

#### 예외 흐름

- 권한 없는 지역 또는 콘텐츠에 연결하려는 요청은 거부한다.
- 다른 지역·발급 경로의 쿠폰 정책을 완료 보상으로 연결하거나, `PUBLISHED`가 아닌 보상 정책으로 스탬프북을 공개하려는 요청은 거부한다.
- 공개되지 않았거나 종료된 스탬프북은 방문자 목록에 노출하지 않는다.
- 종료된 스탬프북의 적립 조건을 우회해 신규 적립을 만들 수 없다.
- `PUBLISHED` 또는 `ENDED` 스탬프북의 대상 콘텐츠·완료 보상·기타 핵심 값을 수정할 수 없다.

**적용 정책:** `STB-01`, `STB-02`

### US-P1-02. 방문자가 방문 완료 후 적립 이력과 보상 발급 정보를 확인한다

- **주체:** 방문자
- **목표:** 실제 방문이 어떤 스탬프북에 반영됐는지 신뢰할 수 있게 확인한다.
- **선행 조건:** 방문자에게 유효 방문 기록이 있다.

#### 기본 흐름

1. 방문 완료 이벤트가 유효 방문 기록을 가리켜 전달된다.
2. 시스템은 현재 공개 중이고 해당 방문에 적용되는 스탬프북을 판별한다.
3. 시스템은 방문 기록과 스탬프북의 조합으로 이미 처리한 적립인지 확인한다.
4. 최초 처리라면 적립 이력과 현재 진행도를 같은 처리 단위로 반영한다.
5. 방문자는 내 스탬프북 상세에서 적립 시각과 근거를 확인한다.
6. 진행이 `COMPLETED`이면 방문자는 내 스탬프북 목록 또는 상세의 `progress.completionReward`에서 완료 보상 쿠폰 정책 식별자와 완료 보상 근거 식별자를 함께 확인해 쿠폰 발급 요청을 구성한다.

#### 예외 흐름

- 동일 방문 이벤트가 반복되면 기존 적립 결과를 반환하고 새 이력을 만들지 않는다.
- 취소·무효 처리된 방문 기록은 적립 근거로 사용할 수 없다.
- 다른 사용자의 스탬프북 상세나 적립 이력은 조회할 수 없다.

**적용 정책:** `STB-03`, `STB-04`

## 3. 스탬프북 정책

- `STB-01`:
  스탬프북은 `DRAFT → PENDING_REVIEW → PUBLISHED → ENDED` 수명주기를 사용하며, 반려는 `PENDING_REVIEW → DRAFT`다.
  콘텐츠 운영자가 작성·검토 요청하고 담당 지역 관리자가 승인해야 공개된다. 공개 전에는 방문자에게 노출하거나 적립하지 않고, 종료 후에는 신규 적립을 중단한다.
  핵심 값은 `DRAFT`에서만 수정하며 `PUBLISHED` 뒤에는 종료만 허용한다.
- `STB-02`:
  생성·수정·공개·종료는 역할, `region_id`, 대상 콘텐츠 소유 관계를 모두 검증한다.
  완료 보상은 같은 지역의 `STAMPBOOK_COMPLETION` 정책이어야 하며, 공개 때 해당 정책도 `PUBLISHED`여야 한다.
  완료 보상 이력의 쿠폰 정책은 원본 스탬프북의 완료 보상 정책과 같아야 한다.
  모든 수명주기 변경에는 처리자, 이전·이후 상태, 사유와 시각을 기록한다.
- `STB-03`:
  적립은 `PUBLISHED` 뒤 `ENDED` 전의 유효 방문이고 대상 콘텐츠에 속할 때만 반영한다. 대상 콘텐츠별로 사용자에게 스탬프 1개만 적립하며, 같은 콘텐츠의 다른 회차 재방문은 추가 스탬프가 아니다.
  `UNIQUE (stampbook_progress_id, content_id)`와 `UNIQUE (stampbook_progress_id, visit_id)`로 콘텐츠 중복 적립과 같은 방문 재전달을 함께 막고, 재시도·중복 이벤트·동시 처리에는 최초 결과를 반환한다.
- `STB-04`:
  방문자는 본인 스탬프북의 현재 진행도, 적립 시각과 근거 방문 정보를 조회할 수 있다.
  본인 진행이 `COMPLETED`이면 내 목록·상세 응답의 `progress.completionReward`에 완료 보상 쿠폰 정책 식별자
  `couponPolicyId`와 완료 보상 근거 식별자 `stampbookRewardGrantId`를 함께 반환한다. 두 식별자는 기존 쿠폰 발급 요청의
  경로 `couponPolicyId`와 `sourceId`를 각각 구성한다. `COMPLETED`가 아닌 진행은 `completionReward = null`이며,
  `completionReward`가 `null`이면 두 하위 식별자는 반환하지 않는다. 타 사용자의 진행 또는 완료 보상 근거는 반환하지 않는다.
  적립 이력은 원본 근거를 덮어쓰지 않으며, 운영 보정이 필요하면 별도 보정 이력과 사유를 남긴다.

## 4. 확정된 핵심 제약

- 대상은 스탬프북 지역에 속한 하나 이상의 콘텐츠이며, 대상 콘텐츠 행 수가 완료 목표다.
- 유효 방문 한 건은 대상 콘텐츠별 스탬프 하나를 만들 수 있다. 같은 콘텐츠의 여러 회차 방문은 추가 적립이 아니다.
- 완료 보상은 같은 지역의 `STAMPBOOK_COMPLETION` 쿠폰 정책 하나이며, 완료 진행당 보상 근거도 하나만 만든다.
- 완료 보상 발급 정보는 본인 `COMPLETED` 진행에만 반환한다. `couponPolicyId`와 `stampbookRewardGrantId`는 하나의
  `completionReward` 객체로 함께 반환하며, 둘 중 하나만 반환하거나 다른 사용자의 값을 반환하지 않는다.
- 공개 전 방문의 소급 적립, 종료 뒤 신규 적립과 종료 뒤 미완료 진행의 보상 지급은 허용하지 않는다. 미완료 진행은 `ENDED_INCOMPLETE`로 보존한다.

## 5. 데이터 요구사항

| 데이터 | 핵심 식별·연결 정보 | 용도 |
| --- | --- | --- |
| 스탬프북 | `stampbook_id`, `region_id`, `reward_coupon_policy_id`, 상태·공개·종료 정보 | 스탬프 적립 규칙과 방문자 노출 |
| 대상 콘텐츠 | `stampbook_id`, `content_id` | 완료 목표와 적립 대상 |
| 사용자 진행 | `stampbook_progress_id`, `stampbook_id`, `user_id`, 상태·완료 시각 | 사용자별 현재 진행과 완료 자격 |
| 스탬프 적립 이력 | `stamp_earn_id`, `stampbook_progress_id`, `visit_id`, `content_id`, 적립 시각 | 콘텐츠·방문 중복 적립 차단과 사용자 이력 |
| 스탬프북 운영 이력 | 대상, 처리자, 이전·이후 상태, 사유, 시각 | 공개·종료와 보정 감사 |
| 완료 보상 근거 | `stampbook_reward_grant_id`, 진행, 쿠폰 정책, 지급 시각 | 쿠폰 발급의 불변 근거 |
| 방문 | `visit_id`, `user_id`, `content_id`, 방문 완료 시각 | 적립 자격의 원본 근거 |

상세 엔티티, 컬럼, 관계, 고유 제약과 인덱스는 [P1 ERD](../p1-erd.md)에 확정하고, P0 재사용 테이블은 [P0 ERD](../erd.md)를 따른다.
