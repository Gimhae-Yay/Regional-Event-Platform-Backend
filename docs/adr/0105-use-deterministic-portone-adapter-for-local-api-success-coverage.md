# ADR-0105: 로컬 API 정상 응답 검증에 결정적 PortOne 어댑터를 사용한다

- 상태: 채택됨
- 기록 유형: 신규
- 기록일: 2026-08-17
- 결정일: 2026-08-17
- 관련 요구사항: [P1 결제·환불 명세](../api/p1/payment/payment.md), [P1 예약 명세](../api/p1/reservation/reservation.md)
- 관련 단계: 단계 1. MVP 구현·검증
- 관련 이슈: 없음
- 대체 대상: 없음

## 맥락

컨트롤러의 모든 정상 응답을 하나의 로컬 k6 실행으로 검증하려면 결제 생성 뒤의 PortOne 웹훅, 환불 및 환불 재시도까지 외부 상태에 의존하지 않고 재현해야 한다. 실 PortOne API는 자격 증명, 네트워크, 샌드박스 결제 상태에 따라 결과가 달라 로컬 fixture의 정상 응답 기준으로 사용할 수 없다.

## 결정 동인과 불변 조건

- 단일 로컬 실행은 역할별 토큰, 고정 fixture 및 유효한 요청 본문으로 반복 가능해야 한다.
- 운영 환경에서는 실 PortOne 어댑터와 서명 검증을 계속 사용해야 한다.
- 가짜 어댑터는 명시적 환경 변수로만 활성화하고, 기본값은 비활성화해야 한다.
- 가짜 결제의 금액·통화·상점·식별자 규칙은 설정 가능하며 결과가 결정적이어야 한다.

## 검토한 선택지

| 순서 | 선택지 | 장점 | 단점·실패 위험 | 되돌림 비용 | 현재 단계 적합성 |
| --- | --- | --- | --- | --- | --- |
| 1 | 로컬 결정적 PortOne 가짜 어댑터 | 네트워크와 결제사 상태 없이 결제·환불·웹훅 정상 경로를 반복 실행한다 | 실 결제사 지연·장애·계약 변경은 측정하지 못한다 | 낮음. 환경 변수를 끄면 실 어댑터를 사용한다 | 높음 |
| 2 | PortOne 샌드박스만 사용 | 실 연동과 유사한 응답을 확인한다 | 계정·네트워크·원격 결제 상태가 필요하고 로컬 재현성이 낮다 | 중간. 테스트 계정과 데이터를 정리해야 한다 | 낮음 |

## 결정

`PORTONE_FAKE_ENABLED=true`일 때만 `PortOnePaymentGateway`의 로컬 결정적 구현과 웹훅 서명 우회 구현을 등록한다. 기본 환경은 기존 실 PortOne 어댑터와 서명 검증을 유지한다. 이 경로는 로컬 k6 API 정상 응답 검증 전용이며, 실 연동 성능이나 운영 승인 근거로 사용하지 않는다.

## 결과와 트레이드오프

### 기대 효과

- 결제·환불·웹훅을 포함한 정상 API 시나리오를 동일 fixture에서 재현할 수 있다.
- 실패한 실행을 외부 결제사 상태와 분리해 API 계약·fixture·코드 문제로 좁힐 수 있다.

### 수용한 단점과 위험

- 가짜 어댑터는 PortOne의 실제 인증, 응답 지연, 오류 형식, 취소 처리 지연을 대체하지 않는다.
- 로컬 k6 결과에는 외부 결제사 왕복 시간이 포함되지 않는다.

## 전환과 롤백

새 구현을 조건부 Bean으로 추가한다. 로컬 실행은 `PORTONE_FAKE_ENABLED=true`과 `IMAGE_STORAGE_FAKE_ENABLED=true`를 명시한다. 문제가 생기면 두 환경 변수를 제거하거나 `false`로 설정해 기존 실 어댑터를 즉시 복구한다. 데이터 이관과 API 호환 계층은 필요하지 않다.

## 검증 방법

- 가짜 어댑터 활성화·비활성화 조건과 결제 조회·취소 결과를 단위 테스트로 검증한다.
- 단일 k6 실행에서 결제 생성, 웹훅, 환불 및 재시도 정상 응답을 역할별 토큰과 고정 fixture로 검증한다.
- 운영 환경에서는 `PORTONE_FAKE_ENABLED`가 비활성화된 것을 배포 설정과 시작 로그로 확인한다.

## 대체 조건

- 실 PortOne 샌드박스를 격리된 fixture와 안정적인 자격 증명으로 자동화할 수 있으면, 결제사 연동 검증을 별도 실행 단계로 추가하는 결정을 검토한다.
- 가짜 어댑터가 운영 프로필에서 활성화되거나 실 연동 계약 검증을 대신하는 근거로 사용되면 이 결정을 재검토한다.
