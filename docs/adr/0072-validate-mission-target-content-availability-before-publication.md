# ADR-0072: 미션 대상 콘텐츠의 작성·공개 가용성 검증

- 상태: 채택됨
- 기록 유형: 신규
- 기록일: 2026-08-07
- 결정일: 2026-08-07

- 관련 이슈: 없음
- 대체 대상: 없음

## 맥락

`CONTENT_SET` 미션은 하나 이상의 P0 콘텐츠를 목표로 사용한다. 작성 단계에서 삭제된 콘텐츠를 연결하거나,
공개 승인 시 목표 콘텐츠가 실제로 공개되지 않았는데 미션만 `PUBLISHED`가 되면 방문자는 완료할 수 없는 미션과
비공개 콘텐츠 제목을 볼 수 있다. 반대로 작성 시점부터 모든 목표 콘텐츠를 `PUBLISHED`로 제한하면 콘텐츠와 미션을
함께 준비하는 운영 흐름을 막는다.

## 결정 동인과 불변 조건

- 미션과 목표 콘텐츠는 같은 지역에 속해야 한다.
- 삭제된 콘텐츠는 새 미션의 목표로 연결하지 않는다.
- 방문자에게 공개되는 `CONTENT_SET` 미션의 모든 목표 콘텐츠는 승인 시점에 공개 상태여야 한다.
- 승인과 콘텐츠 상태 변경이 경합해도 검증하지 않은 목표 콘텐츠를 가진 미션이 공개되면 안 된다.

## 결정

`CONTENT_SET` 미션 생성·수정은 같은 지역이고 `deleted_at IS NULL`인 콘텐츠만 목표로 연결한다. 목표 콘텐츠는
`content_id` 오름차순으로 잠근 뒤 지역과 삭제 여부를 검증한다. 작성 단계에서는 콘텐츠 상태를 제한하지 않아
콘텐츠와 미션을 함께 준비할 수 있게 한다.

미션 승인에서는 보상 정책, 미션, 지역을 잠근 뒤 모든 목표 콘텐츠를 `content_id` 오름차순으로 잠근다. 잠금 뒤
각 콘텐츠가 미션과 같은 지역이고 `deleted_at IS NULL AND status = PUBLISHED`인지 재검증한 경우에만 미션을
`PUBLISHED`로 전이한다. 하나라도 조건을 만족하지 않으면 미션과 감사 성공 이벤트를 만들지 않고 상태 충돌로
종료한다. `VISIT_COUNT` 미션에는 목표 콘텐츠 상태 검증을 적용하지 않는다.

이 결정은 공개 뒤 목표 콘텐츠의 운영 중단·철회·종료와 미션을 자동으로 연동하지 않는다. 해당 상황은 기존 미션
조기 종료 사유로 처리하며, 자동 연동은 별도 요구사항과 동시성 계약이 채택되기 전까지 추가하지 않는다.

## 결과와 트레이드오프

### 기대 효과

- 비공개·삭제 콘텐츠 제목이 공개 미션을 통해 노출되는 것을 막는다.
- 승인 시점에 실제로 방문 가능한 목표로만 미션을 공개한다.
- 콘텐츠와 미션의 작성 일정을 병행할 수 있다.

### 수용한 단점과 위험

- 작성 뒤 콘텐츠가 삭제되거나 공개되지 않으면 승인 요청이 거부될 수 있다.
- 공개 뒤 목표 콘텐츠가 운영 불가 상태가 되면 자동 종료되지 않으므로 운영자가 미션을 조기 종료해야 한다.

## 전환과 롤백

P1 신규 기능이므로 기존 미션 데이터 이관은 없다. 구현은 생성·수정 검증, 승인 잠금·재검증, 오류 응답과 통합
테스트 순서로 적용한다. 승인 검증에 문제가 생기면 미션 공개를 중단하고 `PENDING_REVIEW`를 유지한다. 목표 콘텐츠
검증을 생략하는 방식으로 롤백하지 않으며, 정책을 바꾸려면 후속 ADR로 이 결정을 대체한다.

## 검증 방법

- 다른 지역 또는 삭제된 콘텐츠를 목표로 생성·수정하면 거부되는지 확인한다.
- `PENDING`, `APPROVED` 등 비공개 콘텐츠를 포함한 미션 작성은 허용하되 승인 시 거부되는지 확인한다.
- 모든 목표 콘텐츠가 `PUBLISHED`이면 승인과 감사 성공 이벤트가 같은 트랜잭션으로 커밋되는지 확인한다.
- 승인과 목표 콘텐츠 상태 변경이 경합할 때 콘텐츠 잠금과 재검증으로 유효한 한 결과만 커밋되는지 확인한다.
- `VISIT_COUNT` 미션 승인에는 목표 콘텐츠 조회·잠금이 발생하지 않는지 확인한다.

## 대체 조건

- 미션 승인과 콘텐츠 공개를 하나의 운영 작업으로 묶거나, 공개 뒤 목표 콘텐츠 상태에 따라 미션을 자동 종료하는
  요구사항이 채택되면 재검토한다.
