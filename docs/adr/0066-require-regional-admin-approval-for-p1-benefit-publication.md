# ADR-0066: P1 혜택 정책의 지역 관리자 공개 승인

- 상태: 제안됨
- 기록 유형: 신규
- 기록일: 2026-08-05
- 결정일: 2026-08-05
- 관련 요구사항: `docs/p1/stampbook.md`의 `STB-01`~`STB-02`, `docs/p1/regional-mission.md`의 `MSN-01`, `docs/p1/coupon.md`의 `CPN-01`
- 관련 단계: 단계 3. 확장 의사결정
- 관련 이슈: 없음
- 대체 대상: 없음

## 맥락

스탬프북은 검토 통과 뒤 공개하도록 명시돼 있으나, 미션과 쿠폰 정책의 공개 승인자는 세부적으로 고정돼 있지 않다. 세 기능 모두 방문 보상과 할인에 영향을 주므로 공개 뒤 조건을 바꾸면 참여자 기준이 달라진다.

## 결정 동인과 불변 조건

- 콘텐츠 운영자는 담당 콘텐츠 범위에서만 작성한다.
- 공개 전 지역 단위의 품질·혜택 검토가 있어야 한다.
- 공개된 기준은 발급·적립·진행 중 바뀌지 않는다.

## 검토한 선택지

| 순서 | 선택지 | 장점 | 단점·실패 위험 | 되돌림 비용 | 현재 단계 적합성 |
| --- | --- | --- | --- | --- | --- |
| 1 | 추천안: 지역 관리자 승인 뒤 공개 | 혜택 조건과 지역 범위를 한 번 더 검증한다. | 승인 대기 단계가 생긴다. | 낮음 | 높음 |
| 2 | 콘텐츠 운영자 즉시 공개 | 운영이 빠르다. | 잘못된 할인·보상 조건이 즉시 노출될 수 있다. | 중간 | 낮음 |

## 결정

스탬프북·미션·쿠폰 정책은 공통으로 `DRAFT → PENDING_REVIEW → PUBLISHED → ENDED` 수명주기를 사용한다. 콘텐츠 운영자가 작성·검토 요청하고 담당 지역 관리자가 승인해야 `PUBLISHED`가 된다. 반려는 `DRAFT`로 돌려 수정 후 재요청한다.

핵심 내용은 `DRAFT`에서만 수정한다. `PUBLISHED` 뒤에는 종료만 허용하며, 종료된 정책은 수정하지 않는다. 미션은 공개 즉시 시작하고 종료 시각에 자동 종료한다.

## 결과와 트레이드오프

### 기대 효과

- 세 혜택 도메인의 공개·종료 감사 모델이 일관된다.
- 공개 뒤 기준 변경으로 인한 보상 분쟁을 막는다.

### 수용한 단점과 위험

- 긴급한 문구 수정도 종료·재작성 절차가 필요할 수 있다.
- 지역 관리자 검토 대기열 운영이 필요하다.

## 전환과 롤백

P1 신규 기능이므로 기존 공개 데이터를 이관하지 않는다. 승인 기능 장애 시 `PENDING_REVIEW`를 유지하고 자동 공개하지 않는다.

## 검증 방법

- 운영자가 자기 지역 밖의 정책을 제출하거나 승인 없이 공개하는 요청이 거부되는지 확인한다.
- 공개 뒤 조건·할인·대상 콘텐츠 변경이 거부되고 종료만 허용되는지 확인한다.
- 승인·반려·종료마다 처리자·사유·시각의 감사 이벤트가 기록되는지 확인한다.

## 대체 조건

- 지역 관리자 검토를 대체하는 자동 심사 기준이 검증되거나, 역할 분리 정책이 바뀌는 경우 재검토한다.
