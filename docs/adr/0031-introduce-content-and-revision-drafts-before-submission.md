# ADR-0031: 제출 전 콘텐츠와 수정본을 초안 상태로 분리

- 상태: 채택됨
- 기록 유형: 신규
- 기록일: 2026-07-30
- 결정일: 2026-07-30
- 관련 요구사항: [PRD](../local-stamp-platform-prd.md)의 `FR-03`, `FR-14`, `CON-01`, `CON-02`, `CON-05`, `CON-08`
- 관련 단계: 단계 0. 정책·설계 확정, 단계 1. MVP 구현·검증
- 관련 이슈: 없음
- 대체 대상: [ADR-0011](0011-bootstrap-operator-ownership-on-content-creation.md)의 생성 시 `PENDING` 전이 범위, [ADR-0014](0014-store-published-content-edits-in-relational-revision-tables.md)의 수정본 생성·제출 상태 범위

## 맥락

기존 정책과 ERD는 콘텐츠 생성 시 필수 콘텐츠 정보·대표 이미지·회차를 모두 갖춘 `PENDING` 상태를 만들고,
수정본도 곧바로 `EDIT_REQUESTED`로 만든다고 해석했다. 그러나 운영 API는 콘텐츠 생성 뒤 대표 이미지
업로드를 허용하고, 수정본도 생성·편집·제출을 별도 명령으로 제공한다. 기존 상태만으로는 업로드 전 생성과
심사 제출 전 편집의 권한·노출·정합성 경계를 표현할 수 없다.

사용자는 콘텐츠와 수정본 모두 제출 전 초안을 두고, 대표 이미지 업로드는 콘텐츠 또는 수정본을 먼저 생성한
뒤에만 허용하도록 선택했다.

## 결정 동인과 불변 조건

- `DRAFT` 콘텐츠와 `EDIT_DRAFT` 수정본은 공개 목록·상세·예약과 지역 관리자 심사 대기 목록에 노출하지 않는다.
- 초안 생성·편집·이미지 업로드는 승인된 소유 운영자와 담당 지역에만 허용하며, 반려된 콘텐츠도 같은 운영자가 보완할 수 있다.
  클라이언트가 owner·region을 지정할 수 없다.
- 콘텐츠는 `PENDING` 전이에, 수정본은 `EDIT_REQUESTED` 전이에 필요한 후보 필드·대표 이미지·유효 회차 조건을 검증한다.
- 공개 콘텐츠와 공개본 수정 심사 중인 후보는 직접 수정하지 않으며, 승인 반영의 버전 검증·원자성은 ADR-0014를 유지한다.
- S3 객체 키는 서버가 생성하고, 업로드 URL은 이미 생성된 `DRAFT` 콘텐츠 또는 `EDIT_DRAFT` 수정본에만 연결한다.

## 검토한 선택지

| 순서 | 선택지 | 장점 | 단점·실패 위험 | 되돌림 비용 | 현재 단계 적합성 |
| --- | --- | --- | --- | --- | --- |
| 1 | 콘텐츠 `DRAFT`와 수정본 `EDIT_DRAFT`를 만든 뒤 각각 심사 상태로 제출 | 생성·편집·업로드·제출 API의 순서를 상태로 명확히 표현하고, 불완전한 정보가 심사·공개로 노출되는 것을 막는다. | 상태·조건부 제약·초안 정리 경로가 늘어난다. | 중간. 상태 제약과 API 흐름을 변경해야 한다. | 사용자가 선택했으며 분리된 운영 API에 가장 적합하다. |
| 2 | 콘텐츠와 수정본을 생성 즉시 심사 상태로 둠 | 상태 수가 적고 기존 ERD 해석을 유지한다. | 이미지 업로드와 편집이 심사 중 상태를 바꾸거나, 불완전한 콘텐츠를 제출해야 한다. | 낮음 | 제공된 API 순서와 맞지 않는다. |
| 3 | 콘텐츠 생성 전 임시 S3 객체를 업로드하고 생성 시 연결 | 이미지 선업로드 UX를 제공할 수 있다. | 소유·지역 문맥 없는 객체의 권한 검증과 고아 객체 정리가 필요하다. | 높음 | 사용자가 선택한 생성 후 업로드 방식과 맞지 않는다. |

## 결정

승인된 운영자가 콘텐츠를 생성하면 서버는 인증된 운영자와 담당 지역을 연결한 `DRAFT` 콘텐츠를 만든다.
`DRAFT`에서는 운영자가 콘텐츠·회차·대표 이미지를 편집할 수 있으나, 공개·예약·심사 조회에는 노출하지 않는다.
`POST /operator/contents/{contentId}/submit`은 모든 필수 필드, 현재 대표 이미지 한 개, 유효 회차 한 개 이상을
검증한 뒤 `DRAFT → PENDING` 또는 `REJECTED → PENDING`으로 전이한다.

공개 콘텐츠의 수정 요청은 `EDIT_DRAFT` 수정본을 만든다. 소유 운영자만 이를 편집할 수 있고,
`POST /operator/content-revisions/{revisionId}/submit`이 후보 필드와 후보 대표 이미지를 검증한 뒤
`EDIT_DRAFT → EDIT_REQUESTED`로 전이한다. 초안 또는 심사 중 수정본의 철회는 각각 `EDIT_DRAFT → EDIT_WITHDRAWN`,
`EDIT_REQUESTED → EDIT_WITHDRAWN`으로 전이한다. 반려·승인은 기존 `EDIT_REQUESTED → EDIT_REJECTED`,
`EDIT_REQUESTED → EDIT_APPROVED` 규칙을 유지한다. `POST /operator/content-revisions/{revisionId}/withdraw`는 두 철회
전이를 모두 처리한다. 초안 철회는 제출 스냅샷이 아니므로 후보 대표 이미지 연결을 제거하고, 심사 중 철회는 당시 후보
스냅샷을 보존한다. 두 철회 상태는 활성 수정본이 아니므로 새 초안 생성을 막지 않는다.

대표 이미지 업로드 URL은 `DRAFT` 또는 `REJECTED` 콘텐츠, `EDIT_DRAFT` 수정본을 먼저 생성한 소유 운영자에게만 발급한다.
서버는 생성한 `image_object`와 객체 키를 해당 루트에 연결하고, 심사 제출 시 업로드된 현재 이미지가 유효한지
확인한다. 콘텐츠 생성 전 임시 업로드, 공개 콘텐츠 직접 이미지 교체와 임의 객체 키 연결은 허용하지 않는다.

## 결과와 트레이드오프

### 기대 효과

- 콘텐츠 생성·편집·이미지 업로드·승인 요청의 API 순서가 상태 전이와 일치한다.
- 미완성 데이터가 심사 대기·공개 조회·예약 경로에 나타나지 않는다.
- S3 업로드의 소유·지역 검증 시점이 존재하는 콘텐츠 또는 수정본 루트에 고정된다.

### 수용한 단점과 위험

- 콘텐츠와 수정본 상태·조건부 유일성·초안 삭제 검증이 추가된다.
- 초안에 업로드한 이미지가 제출되지 않거나 초안이 삭제되면 즉시 삭제 대상 판정과 S3 재시도가 필요하다.
- 운영자는 공개 전 대표 이미지를 등록하려면 먼저 콘텐츠 초안을 생성해야 한다.

## 전환과 롤백

구현 전 문서·스키마 결정이므로 기존 데이터 이관은 없다. Flyway로 콘텐츠·수정본 상태 제약과 활성 초안
조건부 유일성을 추가한 뒤, 초안 생성·편집·이미지 URL 발급·제출 순으로 구현한다. 공개 조회와 예약 경로는
`PUBLISHED` 원본만 읽는 기존 규칙을 유지한다.

도입 중 문제가 발생하면 초안 생성·업로드 URL 발급·제출 명령을 중지하고 기존 공개 콘텐츠 조회를 유지한다.
승인된 공개본을 초안 상태로 되돌리지 않으며, 이미 업로드했으나 참조가 제거된 객체는 ADR-0016과 ADR-0029의
즉시 삭제·재시도 규칙을 따른다.

## 검증 방법

- `DRAFT` 콘텐츠와 `EDIT_DRAFT` 수정본이 공개·예약·심사 대기 목록에 노출되지 않는지 검증한다.
- 필수 필드·대표 이미지·유효 회차가 누락된 초안은 심사 상태로 전이하지 않는지 검증한다.
- 반려된 콘텐츠에서 소유 운영자가 필드·대표 이미지를 보완해 다시 `PENDING`으로 제출할 수 있는지 검증한다.
- 다른 운영자·다른 지역 관리자·미승인 신청자는 초안·반려 콘텐츠 편집과 업로드 URL 발급을 할 수 없는지 검증한다.
- 콘텐츠당 활성 `EDIT_DRAFT` 또는 `EDIT_REQUESTED` 수정본이 동시에 둘 이상 생기지 않고, 초안 철회 뒤에는 새 수정본을
  만들 수 있는지 검증한다.
- 승인 반영에서 원본 버전 검증, 원본 갱신, 수정본 종결과 감사 이벤트가 함께 커밋되는지 검증한다.
- 업로드 실패·미참조 초안 삭제·이미지 교체 뒤 S3 객체가 공개되지 않고 삭제 재시도되는지 검증한다.

## 대체 조건

- 생성 전 임시 미디어 업로드가 제품 요구사항으로 확정된다.
- 한 콘텐츠의 병렬 초안·공동 편집·다수 후보 심사가 필요해 활성 초안 한 건 제약을 유지할 수 없게 된다.
- 콘텐츠 등록 흐름이 외부 CMS나 대량 가져오기 시스템으로 이전된다.
