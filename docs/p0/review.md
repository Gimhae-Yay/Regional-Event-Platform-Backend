### 기능 범위

- 유효한 방문 기록 한 건에 별점·텍스트 후기 한 건만 작성할 수 있다.
- 별점은 `1` 이상 `5` 이하의 정수이며, 후기 텍스트는 공백만으로 구성할 수 없고 `1`자 이상 `2000`자 이하여야 한다.
- 작성자 연결을 검증할 수 있는 활성 회원은 등록 후 30일 동안 후기를 수정할 수 있다.
- 작성자 연결을 검증할 수 있는 활성 회원은 기간 제한 없이 후기를 삭제할 수 있으며
  삭제 즉시 공개 조회에서 제외한다.
- 삭제한 후기의 별점·텍스트 원문은 삭제 시점부터 30일 후 영구 삭제한다.
- 회원 탈퇴는 후기 삭제와 구분한다. 작성자 연결을 제거한 기존 공개 후기는
  별점·텍스트와 공개 상태를 유지하고 작성자를 공통 `탈퇴한 사용자`로 표시한다.
- 공개 후기에서 작성자 연결이 유지되는 회원도 이름·연락처 대신 공통 `인증 방문자`로 표시한다.

후기 사진, 운영자 답글, 별도 신고 화면과 지역별 후기 피드는 P0 범위에 포함하지 않는다.

### 연결 유저 시나리오

#### US-04. 방문자가 인증 후기를 작성·수정·삭제한다

- **주체:** 체크인 완료 방문자
- **목표:** 실제 경험을 후기 형태로 공유하고 확정된 기간과 삭제 정책에 따라 관리한다.
- **선행 조건:** 개인 연결이 유지된 방문 기록이 생성됐으며 같은 방문 기록에 연결된 후기가 아직 없다.

##### 기본 흐름

1. 사용자가 체크인 완료 화면 또는 예약 내역에서 후기 작성으로 이동한다.
2. 별점과 텍스트를 입력해 후기를 등록한다.
3. 시스템은 후기를 방문 기록과 콘텐츠에 연결한다.
4. 등록된 후기는 해당 콘텐츠 상세에 노출된다.
5. 작성자 연결과 활성 회원 상태가 유지되면 허용된 기간 안에 후기를 수정할 수 있다.
6. 작성자 연결과 활성 회원 상태가 유지되면 기간 제한 없이 후기를 삭제할 수 있다.
7. 삭제한 후기는 즉시 비노출 상태가 되고 보존 기간 후 영구 삭제된다.

##### 예외 흐름

- 체크인하지 않은 사용자는 후기를 작성할 수 없다.
- 동일 방문 기록에 대한 중복 후기는 차단하거나 기존 후기 수정 흐름으로 안내한다.
- 수정 허용 기간이 지난 후기는 수정할 수 없다.
- 삭제한 후기는 사용자 또는 관리자가 복구할 수 없다.
- 회원 탈퇴로 작성자 연결이 제거된 후기는 기존 계정이나 재가입 계정이 수정·삭제할 수 없다.

**적용 정책:** `REV-01`~`REV-04`, `PRV-02`

### 후기 정책

#### `REV-01`

유효한 방문 기록 한 건에 별점·텍스트 후기 한 건만 작성할 수 있다.
체크인하지 않은 사용자는 후기를 작성할 수 없으며 후기에는 해당 방문 기록과 콘텐츠를 연결한다.
회원 탈퇴 완료 후에는 작성자 연결이 제거된 방문과 후기만 남기므로 새 후기 작성 자격으로 재사용하지 않는다.
별점은 `1` 이상 `5` 이하의 정수여야 한다.
후기 텍스트는 `null`이거나 공백만으로 구성할 수 없으며 `1`자 이상 `2000`자 이하여야 한다.

#### `REV-02`

후기 상태는 `PUBLISHED → DELETED`로 전이한다.
등록된 `PUBLISHED` 후기는 해당 콘텐츠 상세에 공개한다.
작성자 연결이 유지되는 공개 후기는 사용자 식별자·이름·연락처를 노출하지 않고 공통 `인증 방문자`로 표시한다.
회원 탈퇴에 따른 작성자 연결 제거는 상태 전이가 아니며 기존 `PUBLISHED` 후기의 별점·텍스트와 공개 상태를
유지하고 작성자를 공통 `탈퇴한 사용자`로 표시한다.

#### `REV-03`

작성자 연결을 검증할 수 있는 활성 회원은 후기 등록 후 **30일 동안** 내용을 수정할 수 있다.
등록 후 30일이 지나면 수정 요청을 거부한다.

#### `REV-04`

작성자 연결을 검증할 수 있는 활성 회원은 기간 제한 없이 후기를 삭제할 수 있다.
삭제 즉시 공개 조회에서 제외하고 사용자와 관리자 모두 복구할 수 없으며,
삭제 시점부터 **30일 후** 별점·텍스트 원문을 영구 삭제한다.
삭제 후 회원이 탈퇴해도 후기를 복구하거나 30일 파기 시계를 다시 시작하지 않는다.
후기 삭제와 회원 탈퇴가 경합하면 활성 회원·작성자 연결과 후기 상태를 조건으로 먼저 성공한 처리만 적용한다.
삭제가 먼저 성공하면 기존 삭제 수명주기를 유지하고, 탈퇴 시작이 먼저 성공하면 이후 삭제 요청을 거부한다.
파기 작업의 실행 주기·배치·재시도와 중복 실행 계약은
[후기 삭제 원문 파기 스케줄러](review-text-purge-scheduler.md)를 따른다.

후기 작성 자격이 되는 방문 기록은 [예약 QR·체크인](check-in.md#qr-03),
회원 탈퇴 후 개인 연결 제거는 [인증·프로필](auth-profile.md#prv-02)을 적용한다.
탈퇴 처리에서는 공개 상태와 원문을 유지하고 작성자 계정 연결만 비가역적으로 제거하며,
작성자 삭제에서는 즉시 비공개 후 30일 파기를 적용한다.
상세 불변 조건은
[ADR-0012](../adr/0012-retain-author-unlinked-reviews-and-visits-after-withdrawal.md)를 따른다.

| 데이터 | 핵심 식별·연결 정보 | 용도 |
| --- | --- | --- |
| 방문 | `visit_id`, 예약 중복 방지 연결, 활성 회원 연결, content_id, session_id, checked_at, 작성자 연결 제거 상태 | 후기 작성 자격과 탈퇴 후 작성자 비연결 방문 사실 |
| 후기 | `review_id`, 방문 연결, 활성 작성자 연결, content_id, rating, text, status, deleted_at, 작성자 연결 제거 상태 | 인증 후기, 탈퇴 후 작성자 비연결 공개 유지와 삭제 수명주기 |
