> 이 문서는 원문의 정책을 변경하지 않는다.
> 아래 내용은 별도 표시가 없는 한 현재 무료 예약 MVP의 구현 요구사항이나 출시 차단 조건이 아니다.

전체 관리자는 후속 릴리스에서 별도 제품 정책과 기술 결정으로 도입할 장기 역할이다.
현재 무료 예약 MVP에는 전체 관리자 역할·계정·화면·API와 지역 범위 우회 기능을 포함하지 않는다.

## 1. P1 요구사항

### FR-12. 알림 이벤트

예약 확정, 행사 전 리마인드, 취소·변경, 체크인 성공 이벤트를 발행한다.
알림 전달 채널은 현재 MVP의 출시 기준이 아니며 별도 기술 결정으로 확정한다.

### FR-13. 요청 제한

로그인, 예약 확정, QR 스캔에 사용자/IP 기준 제한과 `429` 정책을 적용한다.
구체적인 임계값은 정상 현장 운영을 방해하지 않는 수준으로 부하 테스트에서 정한다.

## 2. 유료 예약 도입 시 적용할 거래 정책

다음 정책은 방향이 확정됐지만 현재 무료 예약 MVP의 구현 요구사항은 아니다.

- 유료 예약 도입 시 사용자의 회차 시작 전 취소와 운영자 취소는 전액 환불한다.
- 운영자 취소 시 사용한 쿠폰을 복구한다.
- 결제 취소 실패와 예약·결제 불일치의 수동 처리 책임자는 **플랫폼 전체 관리자**다.
- 행사·체험 운영자는 결제 문제의 1차 확인과 고객 안내를 담당한다.
- 지역 관리자는 결제 상태를 변경할 수 없다.

유료 결제·쿠폰·Redis 분산 락·프런트엔드는 후속 MVP 또는 별도 기술 결정 범위로 이관한다.

## 3. 장기 제품 정의

로컬스탬프는 지역 콘텐츠를 발견하는 순간부터 예약·방문·후기·재방문까지 연결해,
실제 방문 기록을 기반으로 지역 참여를 확장하는 플랫폼을 지향한다.

장기 제품의 핵심 흐름은 다음과 같다.

```text
지역 콘텐츠 등록·승인
→ 탐색
→ 예약·결제 또는 현장 방문
→ QR 인증
→ 인증 후기·쿠폰
→ 스탬프·지역 미션
→ 재방문
→ 운영·지역 성과 확인
```

장기 제품은 다음 원칙을 따른다.

- 모든 후기, 쿠폰, 스탬프와 미션 달성은 신뢰할 수 있는 방문 기록을 근거로 삼는다.
- 예약형 행사·체험과 비예약형 가게·관광지는 서로 다른 방문 인증 규칙을 사용한다.
- 예약·결제·방문·혜택의 상태와 이력은 중복 요청과 실패 재시도에서도 일관되게 유지한다.
- 콘텐츠와 운영 데이터는 지역에 연결하고 역할·지역·소유 관계에 따라 접근 범위를 제한한다.
- 기능은 검증된 데이터와 운영 역량을 진입 조건으로 삼아 단계적으로 확장한다.

## 4. 역할별 장기 가치

| 역할 | 장기 제품에서 얻는 가치 | 주요 제품 접점 |
| --- | --- | --- |
| 주말 나들이 방문자 | 낯선 지역의 콘텐츠를 발견하고 예약·방문한 뒤 후기와 재방문 혜택을 얻는다. | 지역 탐색, 예약·결제, QR 인증, 후기, 쿠폰 |
| 지역 주민·재방문 사용자 | 가까운 지역의 새 콘텐츠를 발견하고 반복 방문과 지역 참여 동기를 얻는다. | 지역 홈, 쿠폰, 스탬프북, 지역 미션 |
| 소상공인 운영자 | 가게·체험을 알리고 방문 인증과 후기·혜택을 재방문으로 연결한다. | 콘텐츠 등록, 방문 인증, 쿠폰, 후기 관리 |
| 행사·체험 운영자 | 회차·정원·예약·결제와 현장 참가를 하나의 운영 흐름으로 관리한다. | 회차, 예약자, 결제·취소, QR 체크인, 운영 통계 |
| 지역 관리자 | 담당 지역의 운영자·콘텐츠·혜택 정책을 관리하고 지역 참여 성과를 확인한다. | 승인·반려, 운영 상태, 지역 정책, 성과 리포트 |
| 전체 관리자 | 지역·역할·공통 정책을 통제하고 지역 간 경계와 에스컬레이션을 관리한다. | 지역·권한 설정, 감사 이력, 운영 예외, 공통 정책 |

## 5. 장기 제품 기능 영역

| 기능 영역 | 장기 범위 | 공통 기준 |
| --- | --- | --- |
| 콘텐츠·탐색 | 행사·체험·가게·관광지, 지도, 추천 코스와 개인화 탐색 | 공개 상태와 지역 경계를 적용하고 최신 운영 정보를 제공한다. |
| 예약·거래 | 무료·유료 예약, 정원 홀드, 결제, 취소·환불 | 예약과 결제 상태를 분리하고 모든 변경을 멱등하게 처리한다. |
| 방문 인증 | 예약 QR 체크인, 가게·관광지의 비예약 방문 인증 | 위·변조와 중복을 차단하고 유효한 방문 기록을 한 건만 생성한다. |
| 후기·신뢰 | 방문 인증 기반 후기, 사진, 운영자 답글과 신고 | 방문 자격, 개인정보, 수정·삭제와 공개 정책을 강제한다. |
| 혜택·참여 | 재방문 쿠폰, 스탬프북, 지역 미션과 혜택 지갑 | 방문·예약·결제 이력을 발급과 사용 근거로 연결한다. |
| 운영·권한 | 운영자·콘텐츠 승인, 지역 정책, 전체 관리자 통제 | 역할·지역·소유 관계와 감사 이력으로 변경 권한을 제한한다. |
| 데이터·성과 | 탐색·예약·방문·재방문·혜택·지역 성과 분석 | 지표의 분모·기간·지역을 고정하고 비식별 집계 데이터를 사용한다. |

## 6. 단계별 제품 확장 로드맵

| 제품 단계 | 목표 | 포함 기능 | 다음 단계 진입 조건 |
| --- | --- | --- | --- |
| 현재 기반 | 예약과 실제 참여를 신뢰할 수 있게 연결 | 행사·체험 탐색, 무료 예약, 10분 홀드, 일회성 QR, 인증 후기, 지역 격리 | 현재 MVP 범위 완료 |
| 거래·재방문 확장 | 예약 거래와 첫 재방문 동기를 연결 | 유료 예약, 결제·취소·환불, 체크인 기반 다음 예약 쿠폰 | 예약·체크인 데이터 신뢰성, 결제·쿠폰 정책과 멱등성 검증 |
| 지역 참여 확장 | 예약 외 지역 방문과 반복 참여를 연결 | 가게·관광지 상세, 비예약 방문 인증, 스탬프북, 지역 미션 | 부정 인증 방지, 충분한 콘텐츠 밀도, 쿠폰 재방문 효과 확인 |
| 탐색·성과 고도화 | 데이터 기반 탐색과 운영 판단 개선 | 지도, 추천 코스, 개인화·AI 추천, 고도화된 성과 리포트 | 데이터 품질, 추천 근거, 개인정보·편향과 운영 활용성 검증 |

이 로드맵은 기능 순서와 진입 조건을 정의하며 출시 일정을 확정하지 않는다.
각 단계는 별도 정책 결정과 수용 기준을 가진 독립적인 릴리스로 계획한다.

## 7. 장기 제품 성과 프레임

장기 제품 지표는 제품 확장 여부를 판단하기 위한 기준이다.

| 목표 | 대표 지표 | 활용 시점 |
| --- | --- | --- |
| 콘텐츠 발견 | 지역 홈 대비 상세 진입률, 사용자당 탐색 콘텐츠 수 | 현재 기반부터 관찰 |
| 예약 전환 | 예약 가능한 상세 방문 대비 예약 확정률, 결제 도입 후 결제 성공·실패율 | 현재 기반·거래 확장 |
| 실제 참여 | 예약 확정 대비 체크인율, QR 실패율과 실패 사유 | 현재 기반부터 관찰 |
| 재방문 | 체크인 사용자 재예약률, 쿠폰 발급 대비 사용률 | 거래·재방문 확장 |
| 지역 참여 | 스탬프 적립률, 미션 참여·완료율, 가게·관광지 인증 방문 수 | 지역 참여 확장 |
| 운영 효율 | 콘텐츠 승인 처리 시간, QR 예외 처리 시간, 운영 가능한 콘텐츠·회차 수 | 현재 기반부터 관찰 |
| 지역 성과 | 지역별 인증 방문·재방문·혜택 사용, 유료 도입 후 거래 규모 | 거래 확장 이후 |

각 확장 단계에 착수하기 전에 지표의 분자·분모, 집계 기간, 지역·콘텐츠 구분과 목표치를
별도 운영 계획으로 확정한다.
개인 단위 분석은 목적에 필요한 최소 데이터만 사용하고 외부 보고에는 비식별 집계를 사용한다.
