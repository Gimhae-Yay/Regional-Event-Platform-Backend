# 로컬스탬프 무료 예약 MVP 페르소나

## 1. 주말 나들이 방문자 — 김서연, 29세

- 직업/상황: 서울 직장인, 주말마다 친구·연인과 김해시·동해시의 행사와 체험을 찾음
- 목표: 낯선 지역에서도 믿을 만한 행사·체험을 한곳에서 비교하고 무료 예약부터 현장 참여까지 완료하고 싶음
- 행동: SNS·지도 앱으로 장소를 찾고, 공개된 콘텐츠의 상세 정보·회차·잔여 정원·인증 후기를 확인한 뒤 참여를 결정함
- 불편: 행사 정보가 여러 채널에 흩어져 있고, 실제 예약 가능 여부와 남은 자리를 알기 어려우며 신청과 현장 확인도 서로 다른 도구에서 이루어짐
- 기대: 지역별 행사·체험 탐색, 예약 가능 여부 필터, 10분 정원 홀드, 무료 예약, 일회성 QR 체크인, 방문 인증 후기
- 핵심 이용 흐름: 지역 선택 → 행사·체험 탐색 → 회차·잔여 정원 확인 → 10분 홀드 → 무료 예약 확정 → QR 제시 → 인증 후기
- 대표 문장: “어디를 갈지 찾는 것부터 남은 자리 확인과 현장 참여까지 한 번에 끝내고 싶어요.”

## 2. 지역 주민·재방문 사용자 — 이민호, 35세

- 직업/상황: 김해시 또는 동해시 거주자, 가족과 함께 참여할 지역 행사·체험을 자주 찾음
- 목표: 익숙한 지역의 새로운 행사·체험을 발견하고 원하는 회차에 안정적으로 참여하고 싶음
- 행동: 지역 커뮤니티와 지인 추천을 참고하고, 일정·연령·준비물·잔여 정원을 비교해 가족이 참여할 프로그램을 선택함
- 불편: 지역 행사를 늦게 알거나 회차별 신청 가능 여부를 확인하기 어렵고, 예약 내역과 실제 참여 기록이 일관되게 연결되지 않음
- 기대: 지역 홈과 기본 필터를 통한 탐색, 회차별 무료 예약, 예약 상태·취소 확인, QR 체크인, 실제 방문에 연결된 후기
- 핵심 이용 흐름: 지역 홈 → 행사·체험 탐색 → 상세·회차 확인 → 무료 예약 → 예약 내역·QR 확인 → 체크인 → 인증 후기
- 대표 문장: “우리 지역의 새 체험을 제때 발견하고, 가족과 참여할 회차를 확실하게 예약하고 싶어요.”

## 3. 예약형 행사·체험 운영자 — 최도윤, 38세

- 직업/상황: 김해시 또는 동해시에서 날짜·회차와 정원이 있는 축제·공연·교육·공방 체험을 기획하고 운영함
- 목표: 콘텐츠 등록과 회차별 무료 예약, 예약자 확인, 현장 체크인을 하나의 운영 흐름으로 관리하고 싶음
- 행동: SNS·지역 커뮤니티로 참가자를 모집하고, 전화·메신저로 신청을 받은 뒤 스프레드시트나 수기 명단으로 현장 참여를 확인함
- 불편: 신청과 명단, 현장 확인이 분리되어 초과 예약·누락·중복 체크인이 발생하고 QR을 제시하지 못한 예약자를 일관된 기준으로 처리하기 어려움
- 기대: 운영자 승인, 콘텐츠·회차·정원·공개 예정 시각 등록, 승인·수정 요청, 마스킹된 예약자 조회, QR 체크인과 예약 번호 보조 조회
- 핵심 이용 흐름: 운영자 승인 → 콘텐츠·회차 등록 → 지역 관리자 승인 → 예약된 시각에 자동 공개 → 예약자 확인 → 현장 QR 체크인 → 예외 기록
- 대표 문장: “회차별 신청자와 실제 참가자를 따로 대조하지 않고, 현장에서 정확하게 확인하고 싶어요.”

## 4. 지역 관리자 — 박서연, 42세

- 직업/상황: 김해시 또는 동해시의 관광재단·문화재단·지역 활성화 운영사에서 운영자와 행사·체험을 관리하는 담당자
- 목표: 담당 지역의 운영자 자격과 콘텐츠 공개 품질을 검증하고 현장 운영 예외를 추적 가능한 방식으로 처리하고 싶음
- 행동: 사업자 정보·담당 지역·콘텐츠 소유 관계를 확인하고, 전달받은 콘텐츠와 공개 예정 시각을 검토하며 운영 이슈를 개별 문서와 메신저로 조율함
- 불편: 운영자 검증, 콘텐츠 승인·수정·중단 이력과 QR 예외 기록이 여러 채널에 흩어져 처리자·시각·사유를 다시 확인하기 어려움
- 기대: 운영자 수동 승인, 콘텐츠·공개 예정 시각 승인·반려, 수정 심사·운영 중단·철회 관리, QR 실패·보조 조회 확인, 감사 가능한 처리 이력
- 핵심 이용 흐름: 운영자 검증·승인 → 콘텐츠·공개 시각 검토 → 승인·반려 → 수정·운영 상태 관리 → QR 예외 확인 → 필요 시 전체 관리자 에스컬레이션
- 대표 문장: “담당 지역의 공개 품질과 현장 예외를 통제하고, 모든 처리 근거를 다시 확인할 수 있어야 해요.”
